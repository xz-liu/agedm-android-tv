# 0.3.6：详情页追更信息

标题下的现有信息区增加最新集数和 AGE 最近更新时间，不增加遥控器焦点或操作按钮。例：`连载 · 第05集`，下一行 `AGE 最近更新：今天 11:31（本地时间）`；更早的更新显示完整日期和时间。

2026-11-01 检查 AGE 详情接口：`video.uptodate` 为最新更新标签，`video.time` 为 Unix 秒，`video.time_format_3` 是对应的北京时间。例如《战车椅子》的时间为 `1793550686`，对应北京时间 `2026-11-02 00:31:26`，在印第安纳波利斯显示为 `2026-11-01 11:31`。

优先使用 Unix 时间，仅在其缺失或无效时解析站点格式化时间。不使用刷新请求时间、缓存写入时间或周播计划。最新标签中的 `23:00` 等播出时刻从集数展示中去除，避免与实际更新时间混淆。

新字段随详情缓存、刷新和离线详情保存；旧缓存没有新字段时正常读取，未提供有效时间时隐藏时间行。返回详情页时重新计算今天/昨天，继续使用现有的超过五分钟刷新机制。

测试覆盖数字/字符串时间、格式化时间回退、无效和缺失数据、API 到详情映射、缓存序列化、跨时区日期及夏令时。另用 Android 布局渲染检查标题区的显示。

全部 60 项测试、`lintDebug`、Debug/Release 构建通过。版本为 0.3.6 / versionCode 11。
