# 0.2.2：追更、导航与离线下载

## 修改

- 详情页新增“播放最新集”、可持久保存的正序/倒序选集。只改变显示顺序，播放和自动下一集仍按原始顺序运行。
- 进入详情页强制联网刷新，返回停留较久的详情页也刷新；短 TTL 与 14 天冷驱逐分离。过期缓存不会因读取而删除，网络失败时可回退。
- 补充源刷新会替换同 key 的旧剧集列表。过滤缺失地址的分集后重建连续索引，避免点选错集或越界。
- 扫码页保留左右滑动进入，焦点切换只接受本次左右按键的目标；搜索页的导航焦点改为首页。离开主界面取消待执行的焦点切换，长按 UP 不再模拟双击设置。
- 手机投送由前台 Activity 原子消费，避免切换页面期间多个 Activity 重复打开同一投送。
- 播放解析区分超时与外部取消；旧解析的清理不再停止新解析。备用源异步返回后核对播放请求，避免覆盖已切换的分集。
- 退出前台时暂停播放，切集前保存进度，解析失败不覆盖旧记录，已完成状态不会被定时保存改回未完成。
- 详情页增加“下载选集”和“下载管理”，无需先播放即可下载，主界面“下载”是和扫码、记录一致的导航分区，左右移动焦点即可切换；详情页管理入口和下载通知均定位到同一分区。播放和下载共用独立的 WebView 解析器。增加 Media3 下载服务、下载管理页和独立离线播放器。请求头与元信息随任务保存，下载索引和分片跨进程持久化；离线播放使用下载请求的 stream keys 且禁用网络 upstream。
- 显式声明触摸屏可选，适配无触屏电视；对固定版本 Media3 实验 API 显式 opt-in。

## 验证

运行 `JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease`。

12 项 JVM 回归测试覆盖同源新增集数、合并去重/优先级、空结果保留、缺失分集地址、解析成功/超时/取消，以及导航目标匹配、过期和恢复焦点。没有已连接设备或可用 AVD，以下仍需实机确认：

1. 扫码、首页、目录、推荐、更新、排行、记录、下载八个导航项均左右滑动切换，下载 → 扫码可首尾循环；高亮和指示条同步。首页 → 搜索 → 详情 → 返回时，非按键引发的焦点恢复不应自动跳转。下载为空、删除当前条目、播放返回时，检查上下焦点和 BACK 回首页。
2. 有旧详情缓存的连载打开后出现新集；最新集按钮、倒序点击与自动下一集对应正确。
3. 连续切源/切集、解析超时、返回桌面，确认不跳回旧集、不在后台继续播放。
4. 在详情页选择下载集数，不进入播放器即可准备下载；详情页和首页均能打开下载管理。实际 HLS/MP4 下载，检查暂停继续、进程重启恢复、地址过期、空间不足、删除释放空间。
5. 下载完成后断网，从“下载”播放，验证跳转、音轨、返回后续播；清理内容缓存后仍可播放。

下载服务目前不配置开机调度器，进程被系统结束后需重新打开下载页恢复。离线播放提供 Media3 标准控制栏，暂不自动播放下一集。不同第三方片源的鉴权、分片可用性和地址有效期需实测。

下载设计参考 [Android Media3 下载文档](https://developer.android.com/media/media3/exoplayer/downloading-media)，API 签名以项目固定的 1.4.1 依赖为准。
