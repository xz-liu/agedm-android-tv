# 0.3.1：可配置并行下载

设置页新增“下载 → 同时下载集数”，沿用已有设置行和遥控器单选交互。默认 4 集，可选 1–8 集，修改立即应用到现有 DownloadManager，并保存到偏好设置供下次启动读取。

准备服务改为根据剩余传输空位补充任务，不再等待前一集全部下载完。下载中、已排队和重新启动的请求均占用名额；暂停、失败、完成或其他集的删除不占用名额。同一集仍在删除时等待删除完成再重新加入。数据库中已交接但管理器回调尚未送达的请求也计入，避免连续解析时误判空位。

播放、历史记录和下载海报交互保持原有统一流程。片源解析按空位逐个进行，视频传输按配置并行。修改数量不解除用户对某一集的暂停状态。

验证：30 项测试通过，包含默认值、调高/调低、重建管理器后持久化、无效参数、容量计算、暂停保留和设置项上下焦点。`lintDebug`、`assembleDebug`、`assembleRelease` 均通过；无已连接电视，实际多路传输速度仍需实机验证。
